# STK's Shakers, for the reference test only

Unmodified files from the Synthesis ToolKit in C++ (STK) by Perry R. Cook and Gary P. Scavone
(<https://github.com/thestk/stk>, MIT-style licence: `LICENSE` here, also `LICENSES/STK.txt`): `Stk.h`, `Stk.cpp`,
`Instrmnt.h`, `Shakers.h`, `Shakers.cpp`, `SKINImsg.h`. `tests/shakers_ref.cpp` builds them on the host and renders
every instrument; `tests/shakers_test.c` compares Percolator's fixed-point engine with that. Nothing here goes into
the firmware.
From STK commit `6aacd357d76250bb7da2b1ddf675651828784bbc` (2025-03-29).
